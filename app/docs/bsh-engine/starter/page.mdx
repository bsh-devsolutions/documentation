# Starter

<Callout>
  **Starter** is a planned feature and is **not yet available**.
</Callout>

The upcoming **Starter** tool (website and CLI) will help you configure your `bsh-engine` instance with ease and ensure it is well configured according to best practices.

### What Starter Will Enable

- **Simplified Setup:** Quickly initialize a new Bsh Engine project with guided configuration.
- **Environment Validation:** Ensure your environment variables and runtime settings are correct before deployment.
- **Best Practices:** Automatically apply recommended configurations for security, performance, and scalability.

> More details and usage guides will be added as development progresses. Stay tuned for updates!
