# MFA Integration

<Callout>
  **MFA Integration** is a planned feature and is **not yet available**.
</Callout>

The upcoming **MFA Integration** will add a second layer of security to your Bsh Engine application, supporting multi-factor authentication methods like Authenticator Apps (TOTP), SMS OTP, and more.

### What MFA Integration Will Enable

- **Enhanced Account Security:** Require a second verification step for user logins.
- **Multiple MFA Methods:** Support for popular authenticator apps (Google Authenticator, Authy) and OTP via email/SMS.
- **Flexible Enforcement:** Enable MFA globally or for specific user roles and sensitive operations.

> More details and setup guides will be added as development progresses. Stay tuned for updates!
