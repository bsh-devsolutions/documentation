# Login to BSH Engine

To access the BSH Engine admin panel or protected APIs, users must authenticate using their email and password. The login process creates a secure, authenticated session for subsequent requests.

![Login Page](/images/bsh-egnine/auth/login.png)

<Callout type='info'>
    For detailed request and response formats, refer to the [Authentication API Documentation](/docs/bsh-engine/api/authentication/forgot-password).
</Callout>

<Callout type="error">
  The engine signs tokens with `auth.config.secret`.
  Before starting the instance, set it in your configuration as described in [Authentication configuration](/docs/bsh-engine/environment/compoenents#auth).
</Callout>

Each login opens a new [session](/docs/bsh-engine/security/sessions). Logging in on another device or browser opens another session; the existing ones stay active.
