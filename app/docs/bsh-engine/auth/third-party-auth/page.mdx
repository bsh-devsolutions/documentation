# Third-Party Auth

<Callout>
  **Third-Party Auth** is a planned feature and is **not yet available**.
</Callout>

The upcoming **Third-Party Auth** feature will enable users to authenticate using popular OAuth providers like Google, GitHub, Microsoft, and more, simplifying the registration and login process.

### What Third-Party Auth Will Enable

- **OAuth2 / OpenID Connect:** Seamless integration with major identity providers.
- **Social Login:** Allow users to sign in with their existing social media or professional accounts.
- **Unified Identity:** Link multiple authentication methods to a single Bsh Engine user account.

> More details and provider configuration guides will be added as development progresses. Stay tuned for updates!
