# Changelog

Track all notable changes to BSH Engine.

## 0.0.4 - Upcoming

**Added:**
- Activation email resend endpoint: `/api/auth/resend-activation-email`.
- Password generation option: add `?generatePassword=true` to `/api/users/init` to generate the password.
- User invitation system: admins can invite users with specific roles via `/api/users/invite`.
- Secret management for secure storage of sensitive data. See [Secrets Docs](/docs/bsh-engine/settings#secrets).
- Cookie-based authentication with secure token storage.
- Dynamic JavaScript execution in triggers for advanced automation.
- React starter template for quick engine integration. See [Templates Docs](/docs/bsh-engine/templates).
- Embedded Password verification.
- Api Keys Emails on `create`, `revoke` and `delete`.

**Changed:**
- User IDs now use UUID format for better uniqueness and security.
- Add expiration dates to activation/reset codes (10min).
- Dashboard performance improved with smaller bundles and faster load times.
- Dashboard UI/UX enhancements for better user experience.
- Authentication email templates redesigned for clarity.
- Security improvements across both API and Dashboard.
- Enhanced error handling with more descriptive error messages.

## 0.0.3 - 08 Jan 2026

**Added:**
- Enhanced schema validation with improved error handling and validation rules.
- Additional schema types for more flexible data modeling [Types Docs](/docs/bsh-engine/modeling/types#core-types).
- Contextual request handling system for improved security and request tracking.
- Update Dashboard to display plugins and allow filtering by plugins.
- Build CLI tool for easier working with the engine [CLI Docs](/docs/bsh-engine/cli).
- Allow creating and installing plugins using the CLI [Plugins Docs](/docs/bsh-engine/packaging/plugins).

**Changed:**
- Improved database connection management.
- Synchronized TypeScript library with engine changes for better type safety.
- Upgraded to Spring Boot 4.0.0 for improved performance and security.

## 0.0.2 - 14 Dec 2025

**Added:**
 - Introduce the API Keys system.
 - Add User Update.
 - Implement Register.
 - Introduce Engine Settings.
 - Powered GET requests with search by query parameters.
 - Add count endpoints to the API.
 - Implement TS SDK for quick access to Engine APIs.

**Changed:**
 - Update Pagination to be 1-based.
 - Use new TS library in the dashboard to consume the Engine APIs.
 - Improvements in the Dashboard UI/UX.
 - Security improvements.
 - Internal caching improvements.
 - Fix bugs and improve performance.
