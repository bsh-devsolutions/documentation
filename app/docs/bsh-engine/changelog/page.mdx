# Changelog

Track all notable changes to BSH Engine.

## 0.0.6 - 03 Oct 2026

**Security & Access Controls**
- Fixed vulnerabilities in dependencies.
- Fixed vulnerability: Broken API authorization; anonymous access to privileged endpoints. [#419](https://github.com/bsh-devsolutions/bshengine/issues/419)
- Restricted access to X-Tenant-Id header to only authenticated users. Normal users can only access their assigned tenant. [#434](https://github.com/bsh-devsolutions/bshengine/issues/434)
- Denied access to managed entities (users, tenants, etc.) from generic endpoints `/api/entitites/:entity`. [#420](https://github.com/bsh-devsolutions/bshengine/issues/420)
- Required `BSH_ADMIN` to activate accounts; non-admins cannot set status to ACTIVATED via user update or the generic entity API. [#420](https://github.com/bsh-devsolutions/bshengine/issues/420)
- Restricted assigning `BSH_ADMIN` role to only `BSH_ADMIN` users. [#420](https://github.com/bsh-devsolutions/bshengine/issues/420)
- Improved CORS policy: **`origins.allowed`** accepts only exact origins; wildcard patterns (for example `https://*`, `127.0.0.1:*`) supported before **0.0.6** are no longer valid. [#421](https://github.com/bsh-devsolutions/bshengine/issues/421)
- Enabled CSRF protection for cookie sessions. [#421](https://github.com/bsh-devsolutions/bshengine/issues/421)
- Improved JSON configuration to allow setting for CSRF and auth cookies. [#430](https://github.com/bsh-devsolutions/bshengine/issues/430)
- Fixed access token refresh issue.
- API keys authenticate with `Authorization: <api-key>`. The legacy `X-BSH-APIKEY` header is deprecated.
- Header JWT clients: optional `X-BSH-REFRESHTOKEN`, silent refresh, and `meta.accessToken` on responses. [#443](https://github.com/bsh-devsolutions/bshengine/issues/443)

**Features & Improvements**
- Upgraded Trigger to support lookups. [#375](https://github.com/bsh-devsolutions/bshengine/issues/375)
- Outgoing emails support a **From** display name via `fromName` on send, in [mail provider config](/docs/bsh-engine/mailing/configurations#sender-display-name), or `secrets.mailing.fromName`. [#416](https://github.com/bsh-devsolutions/bshengine/issues/416)

**Testing**
- Added tests to the engine for more robust development and deployment.

## 0.0.4 - 02 Feb 2026

**Highlights**
- Centralized engine configuration using a single JSON object passed via the [`BSH_CONFIG`](/docs/bsh-engine/environment) environment variable.
- [Secret management system](/docs/bsh-engine/settings#secrets) for secure storage of sensitive data.
- Cookie-based authentication with secure token storage.
- New system health checks via `/api/status` and `/status` view to verify setup integrity.
- Move docker repository from `bshg/engine` to [`bshsolutions/engine`](https://hub.docker.com/r/bshsolutions/engine)

**Authentication & Security**
- Cookie-based authentication with secure token storage.
- Embedded password verification.
- Activation and password reset codes now expire after **10 minutes**.
- Default authentication email templates redesigned for clarity.
- Security improvements across both API and Dashboard.

**Users & Access Management**
- User IDs now use **UUID** format for improved uniqueness and security.
- Admin user invitation system with role assignment via [`/api/users/invite`](/docs/bsh-engine/api/users/invite-user).
- Password auto-generation option using [`?generatePassword=true`](/docs/bsh-engine/api/users/init-user#generate-password) on `/api/users/init`.
- Activation email resend endpoint: [`/api/auth/resend-activation-email`](/docs/bsh-engine/api/authentication/resend-activation-email).

**Email & Notifications**
- API key [notification emails](/docs/bsh-engine/mailing/email-templates#authentication-templates) sent on **create**, **revoke**, and **delete** actions.
- Support for [`{{host}}`](/docs/bsh-engine/mailing/email-templates#host-variable) as an internal variable in email templates.

**Plugins & Extensibility**
- Install plugins as ZIP files via [`/api/plugins/install/zip`](/docs/bsh-engine/api/plugins/install-zip).
- Reinstall the core plugin via [`/api/plugins/install/core`](/docs/bsh-engine/api/plugins/install-core).
- Plugin installation history tracking.
- Dynamic JavaScript (ES6) execution in triggers for advanced logic.

**API & System**
- New `/api/status` endpoint for system and setup health checks.
- Improved error handling with clearer and more descriptive error messages.

**Dashboard & UI**
- Improved dashboard performance with smaller bundles and faster load times.
- UI/UX enhancements for a smoother user experience.

**Developer Experience**
- React starter template for faster engine integration. See [Templates Docs](/docs/bsh-engine/templates).
- Add [`docker`](/docs/bsh-engine/cli/docker) command to CLI to generate compose files.
