# BSH Engine 0.0.5

<ReleaseHeader version="0.0.5" />

## New
- Introduced [tenant-based organization](/docs/bsh-engine/security/tenants).
- Released a stable version of [Triggers](/docs/bsh-engine/triggers).
- Added support for [file-based configuration](/docs/bsh-engine/environment/setup#pass-configuration).
- Added admin user management endpoints:
  - [`/api/users/admin/activate-account/{email}`](/docs/bsh-engine/api/users/admin/activate-account)
  - [`/api/users/admin/resend-activation-email/{email}`](/docs/bsh-engine/api/users/admin/resend-activation-email)
  - [`/api/users/admin/forget-password/{email}`](/docs/bsh-engine/api/users/admin/forget-password)
- Added [API key rotation](/docs/bsh-engine/api/api-keys/rotate).

## Improved
- Improved [Dashboard UI/UX](/docs/bsh-engine/settings).

## Security
- Fixed CVSS findings in the built [Docker image](/docs/bsh-engine/installation).
