# Refresh Token

Refresh an expired access token using a refresh token.

```bash
POST /api/auth/refresh
```

## Automatic refresh

<Callout type="info">
  You often <strong>do not</strong> need to call this endpoint on every expiry.
</Callout>

| Client style | Behavior |
|--------------|----------|
| **Cookies** | Expired access tokens are refreshed using the refresh cookie; new cookies are set on the response. |
| **Headers** | Send `Authorization: Bearer <accessToken>` and `X-BSH-REFRESHTOKEN: <refreshToken>`. If the access token is expired, the engine refreshes and completes the original API call. The new access token may appear in **`meta.accessToken`**. |

See [Authentication API — Token usage](/docs/bsh-engine/api/authentication#token-usage) and [SDK Auto Refresh](/docs/bsh-engine/sdk/authentication/auto-refresh).

## Request Body

```json
{
  "refresh": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

## Response

```json
{
  "data": [
    {
      "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
    }
  ]
}
```
