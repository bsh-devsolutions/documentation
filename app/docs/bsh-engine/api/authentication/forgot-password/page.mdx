# Forgot Password

The **Forgot Password** endpoint allows you to request a password reset code via email.

```bash
POST /api/auth/forget-password
```

## Request Body

```json
{
  "email": "user@example.com"
}
```

## Response

```json
{
  "data": [],
  "timestamp": 1234567890,
  "code": 200,
  "status": "OK",
  "meta": {}
}
```

<Callout type='info'>
  If the endpoint succeeds, it will send a [Reset Password Email](/docs/bsh-engine/mailing/email-templates#reset-password) to the email address. The user can then use this code to reset their password.
</Callout>
