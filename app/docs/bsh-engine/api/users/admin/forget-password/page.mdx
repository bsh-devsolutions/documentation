# Forget Password

Trigger the forget password flow for a user.<br/>

```bash
POST /api/users/admin/forget-password/{email}
```

<Callout type='info'>
    This endpoint is for admins to manually trigger the forget password process for a user, sending them a password reset email.
</Callout>

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `email` | string | yes | The email address of the user. |

## Response

```json
{
  "data": true,
  "status": "OK",
  "code": 200,
  "timestamp": 1234567890,
  "meta": {}
}
```
