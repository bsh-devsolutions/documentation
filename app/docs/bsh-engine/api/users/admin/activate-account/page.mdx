# Activate Account

Manually activate a user account by email.<br/>

```bash
POST /api/users/admin/activate-account/{email}
```

<Callout type='info'>
    This endpoint is for admins to activate a user account that has not been activated yet.
</Callout>

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `email` | string | yes | The email address of the user to activate. |

## Response

```json
{
  "data": true,
  "status": "OK",
  "code": 200,
  "timestamp": 1234567890,
  "meta": {}
}
```
