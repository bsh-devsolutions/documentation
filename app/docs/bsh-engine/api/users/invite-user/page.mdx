# Invite User

Invite a new user with email and roles.<br/>

<Callout type='info'>
    This endpoint is for admins to invite new users to the system.
</Callout>

```bash
POST /api/user/invite
```

## Request Body

```json
{
  "email": "user@example.com",
  "roles": ["DEV_USER"]
}
```

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `email` | string | yes | The email address of the user. |
| `roles` | array | no | The roles of the user. |

## Response

```json
{
  "data": [
    {
      "userId": "user-123",
      "email": "user@example.com",
      "roles": ["DEV_USER"]
    }
  ],
  "status": "OK",
  "code": 200,
  "timestamp": 1234567890,
  "meta": {}
}
```

<Callout type='info'>
  User invitation sends an email to the user to notify him.
</Callout>
