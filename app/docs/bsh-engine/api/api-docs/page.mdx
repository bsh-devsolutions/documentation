# API Docs

<Callout>
  **API Docs** integration is a planned feature and is **not yet available**.
</Callout>

The upcoming **API Docs** feature will automatically generate complete documentation for your entities and API endpoints, making it easier for developers to explore and integrate with your Bsh Engine instance.

### What API Docs Will Enable

- **Automatic Documentation:** Always up-to-date API documentation based on your entity schemas and configurations.
- **Interactive API Explorer:** Test your API endpoints directly from the documentation interface.
- **Client Generation:** Use the OpenAPI specification to generate client SDKs for various platforms and languages.

> More details and integration guides will be added as development progresses. Stay tuned for updates!
