# Send Email

Send an email using either plain text, HTML content, or email templates.

<Callout type="error">
  First you need to configure the [email configurations](/docs/bsh-engine/mailing/configurations) before using this endpoint.
</Callout>

## Endpoint

```bash
POST /api/mailing/send
```

## Request Body

Here's the code in markdown format:

<Tabs items={['Direct', 'Template']}>
  <Tabs.Tab title="Direct">
    Send a simple plain text or HTML email directly.

    ```json {6,7,8}
    {
      "to": "recipient@example.com",
      "cc": ["colleague@example.com"],
      "bcc": ["archive@example.com"],
      "subject": "Test Email",
      "body": "This is a test email body",
      "fromName": "BSH Engine",
      "html": false // or true for HTML
    }
    ```
  </Tabs.Tab>

  <Tabs.Tab title="Template">
    Send an email using a predefined [email template](/docs/bsh-engine/mailing/email-templates).

    ```json {5-10}
    {
      "to": "newuser@example.com",
      "cc": ["manager@example.com"],
      "bcc": ["compliance@example.com"],
      "template": "welcome-email",
      "data": {
        "userName": "John Doe",
        "loginUrl": "https://app.example.com/login",
        "supportEmail": "support@example.com"
      }
    }
    ```
    <Callout>
        The `data` object should match the variables defined in your email template. See [email templates documentation](/docs/bsh-engine/mailing/email-templates) for more details.
    </Callout>
  </Tabs.Tab>
</Tabs>

## Parameters

| Parameter  | Type         | Required | Description                                   |
|------------|--------------|----------|-----------------------------------------------|
| `to`       | string/array | Yes      | Recipient email address(es)                   |
| `cc`       | string/array | No       | Carbon copy recipient email address(es)       |
| `bcc`      | string/array | No       | Blind carbon copy recipient email address(es) |
| `subject`  | string       | No       | Email subject line                            |
| `body`     | string       | No*      | Email body content                            |
| `html`     | boolean      | No       | Whether body contains HTML (default: false)   |
| `template` | string       | No*      | Template name for template-based emails       |
| `data`     | object       | No       | Template variables for dynamic content        |
| `fromName` | string       | No       | Human-readable **From** display name (e.g. `BSH Engine` → `BSH Engine <support@example.com>`) |

\* Either `body` or `template` is required, but not both.

## Sender display name

Recipients see the SMTP **From** address from your [mail provider configuration](/docs/bsh-engine/mailing/configurations). When a display name is resolved, the message is sent as `Display Name <address>` instead of the bare address.

Resolution order:

1. **`fromName` in this request** — used when non-blank.
2. **`fromName` in the active mail provider config** — otherwise.

Set a global default via [environment mailing secrets](/docs/bsh-engine/environment#secrets) (`fromName`) or the provider **From Name** field in the admin panel.
