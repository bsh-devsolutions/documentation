# Real-time

<Callout>
    **Real-time** communication is a planned feature and is **not yet available**.
</Callout>

The upcoming **Real-time** feature will enable real-time, bidirectional communication between your application and connected clients.

### What You’ll Be Able to Do with Real-time communication

- **Instant Notifications:** Push updates to users the moment events occur.
- **Live Chat:** Build dynamic messaging and support systems with seamless user interaction.
- **Real-Time Analytics:** Stream and visualize live data dashboards as changes happen.
- etc...

> More details, configuration guides, and practical examples will be added as development progresses. Stay tuned for updates!
