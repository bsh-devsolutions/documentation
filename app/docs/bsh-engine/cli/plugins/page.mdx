# Plugins Commands

The `plugins` command enables to manage [BSH Engine plugins](/docs/bsh-engine/packaging/plugins) from the command line.

## `install`

Archive a plugin directory and install it to a BSH Engine instance using the official SDK.

<Tabs items={['npm', 'npx']}>
    <Tabs.Tab title="npm">
    ```bash
    bsh plugins install <plugin-dir> -H <host> -k <apikey>
    # or
    bsh p i <plugin-dir> -H <host> -k <apikey>
    ```
    </Tabs.Tab>
    <Tabs.Tab title="npx">
    ```bash
    npx @bshsolutions/cli plugins install <plugin-dir> -H <host> -k <apikey>
    # or
    npx @bshsolutions/cli p i <plugin-dir> -H <host> -k <apikey>
    ```
    </Tabs.Tab>
</Tabs>

| Argument | Description | Required | Default |
|----------|-------------|----------|---------|
| `<plugin-dir>` | Path to the plugin directory | yes | ~ |

| Option | Description | Required | Default |
|--------|-------------|----------|---------|
| `-H, --host <host>` | BSH Engine host URL | no | from `.bshsolutions/cli.json` |
| `-k, --apikey <apikey>` | BSH Engine API key | no | from `.bshsolutions/cli.json` |

<Tabs items={['npm', 'npx', 'cli.json']}>
    <Tabs.Tab title="npm">
    ```bash
    bsh plugins install ./path/to/plugin \
      -H https://instance-host.com \
      -k <api-key>
    ```
    </Tabs.Tab>
    <Tabs.Tab title="npx">
    ```bash
    npx @bshsolutions/cli plugins install ./path/to/plugin \
      -H https://instance-host.com \
      -k <api-key>
    ```
    </Tabs.Tab>
    <Tabs.Tab title="cli.json">
    if `.bshsolutions/cli.json` well configured, it will be used to install the plugin.
    ```bash
    npx @bshsolutions/cli plugins install ./path/to/plugin
    ```
    </Tabs.Tab>
</Tabs>
