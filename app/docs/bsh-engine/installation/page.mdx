# Installation

## Prerequisites

- Docker
- Docker Compose

## Installation

<Steps>
### Docker Compose File
Create a new file called `docker-compose.yml` in the root of your project

<Tabs items={['Without Database', 'With Database', 'CLI']}>
    <Tabs.Tab title="Without Database">
```yaml filename="docker-compose.yml" {3}
services:
  backend:
    image: 'bshsolutions/engine:latest'
    container_name: 'engine-backend'
    ports:
      - '7071:7071'
    environment:
      - 'BSH_CONFIG={}'
```
    </Tabs.Tab>
    <Tabs.Tab title="Database Included">
```yaml filename="docker-compose.yml" {3} {15}
services:
  backend:
    image: 'bshsolutions/engine:latest'
    container_name: 'engine-backend'
    ports:
      - '7071:7071'
    environment:
      - 'BSH_CONFIG={}'
    depends_on:
      - postgres
    networks:
      - engine-net

  postgres:
    image: 'postgres:latest'
    container_name: 'engine-postgres'
    environment:
      - 'POSTGRES_DB=engine'
      - 'POSTGRES_PASSWORD=password'
      - 'PGDATA=/var/lib/postgresql/data'
      - 'POSTGRES_USER=engine'
    ports:
      - '5432:5432'
    volumes:
      - ./data/engine-postgres-data:/var/lib/postgresql/data
    networks:
      - engine-net

networks:
  engine-net:
    name: engine-net
    driver: bridge

volumes:
  engine-postgres-data:
```
    </Tabs.Tab>
    <Tabs.Tab title="CLI">
    This will generate the `docker-compose.yml` (including database) file and the `.env` file for you.
    ```bash
    bsh docker setup
    # or
    npx @bshsolutions/cli docker setup
    ```
    </Tabs.Tab>
</Tabs>

### Environment Variables

The engine requires a configs to run, read [this](/docs/bsh-engine/environment) docs for more details.

### Run the Engine

Run the following command to start the engine:

```bash
docker compose up -d
```

<Callout type="info">
    The engine will be available at `http://localhost:7071` or any domain you configured.
</Callout>

### Check status

After the engine is running, check its status at `http://localhost:7071/status` to make sure everything is well configured before you start using it.

### Explore the Endpoints

After the engine is running, you can fork the **BSH Engine** Postman collection from the `postman` workspace to use the exposed endpoints. You can also import the collection into your own Postman workspace.
