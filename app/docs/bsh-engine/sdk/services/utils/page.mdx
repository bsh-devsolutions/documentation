# Utils Service

The Utils Service provides utility methods for retrieving available trigger plugins and actions that can be used when configuring [triggers](/docs/bsh-engine/triggers).

## Methods

### triggerPlugins

Retrieves a list of available trigger plugins that can be used when configuring triggers.

```typescript
await bshEngine.utils.triggerPlugins();
```

### triggerActions

Retrieves a list of available trigger actions that can be executed when triggers fire.

```typescript
await bshEngine.utils.triggerActions();
```

### secrets

Retrieves secrets from a specified source. The source defaults to `'env'` if not provided.

```typescript
// Get secrets from the default 'env' source
await bshEngine.utils.secrets({});

// Get secrets from a specific source
await bshEngine.utils.secrets({ source: 'env' });
```
