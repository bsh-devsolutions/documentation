# Auth Service

The Auth Service provides methods for user authentication, account management, and password recovery.

## Methods

### login

Authenticates a user with email and password credentials.

```typescript
await bshEngine.auth.login({
  payload: {
    email: 'user@example.com',
    password: 'your-password'
  }
});
```

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `email` | string | yes | The user's email address |
| `password` | string | yes | The user's password |

Returns `{ access, refresh }` in `data`. Store both tokens; see [Auto Refresh](/docs/bsh-engine/sdk/authentication/auto-refresh). When the engine uses `Cookies` [delivery](/docs/bsh-engine/environment/compoenents#auth), `data` is empty and the tokens are only set as cookies.

### logout

Ends the current session on the engine (status `LoggedOut`) and clears the auth cookies. Other sessions of the user stay active.

```typescript
await bshEngine.auth.logout({});
```

---

### register

Registers a new user account.

```typescript
await bshEngine.auth.register({
  payload: {
    email: 'user@example.com',
    password: 'secure-password',
    profile: {
      firstName: 'John',
      lastName: 'Doe'
    },
    roles: ['USER']
  }
});
```

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `email` | string | yes | The user's email address |
| `password` | string | yes | The user's password |
| `profile` | object | no | User profile data. This object is customizable; define any fields you want to include in a user's profile |
| `roles` | string[] | yes | Array of role names. Only [public roles](/docs/bsh-engine/security/roles#public-roles) are allowed |

---

### refreshToken

Refreshes the **current session** and returns new `{ access, refresh }` tokens in `data`.

```typescript
const response = await bshEngine.auth.refreshToken();
const tokens = response?.data[0];
if (tokens) {
  localStorage.setItem('accessToken', tokens.access);
  localStorage.setItem('refreshToken', tokens.refresh);
}
```

The previous refresh token stops working shortly after, so always store the new one. See [Refresh Token](/docs/bsh-engine/api/authentication/refresh-token#token-rotation).

### forgetPassword

Sends a password reset code to the user's email address.

```typescript
await bshEngine.auth.forgetPassword({
  payload: {
    email: 'user@example.com'
  }
});
```

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `email` | string | yes | The user's email address where the reset code will be sent |

---

### resetPassword

Resets a user's password using the reset code sent to their email.

```typescript
await bshEngine.auth.resetPassword({
  payload: {
    email: 'user@example.com',
    code: '123456',
    newPassword: 'new-secure-password'
  }
});
```

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `email` | string | yes | The user's email address |
| `code` | string | yes | The reset code received via email |
| `newPassword` | string | yes | The new password to set |

---

### activateAccount

Activates a user account using the activation code sent to their email.

```typescript
await bshEngine.auth.activateAccount({
  payload: {
    email: 'user@example.com',
    code: '123456'
  }
});
```

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `email` | string | yes | The user's email address |
| `code` | string | yes | The activation code received via email |
