# API Key Authentication

The simplest way to authenticate is using an API key:

```typescript
const bshEngine = new BshEngine({
  host: 'https://your-instance.com',
  apiKey: 'your-api-key'
});
```

The SDK sends the key on every request as `Authorization: <your-api-key>`. See [Using your API key](/docs/bsh-engine/security/api-keys#using-your-api-key).

<Callout type="warning">
  Integrations built for engine 0.0.5 and earlier may still send `X-BSH-APIKEY`. That header is deprecated as of 0.0.6; migrate to the SDK default or set `Authorization` manually.
</Callout>
